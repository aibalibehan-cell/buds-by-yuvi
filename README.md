## Overview
Aether 1 Earbuds is a next-generation interactive audio hardware showcase built with Three.js, WebGL 2.0 shaders, GLTF/Draco 3D model loaders, and real-time audio synthesis.

## Features
- **3D Interactive Showcase:** Real-time WebGL rendering of the Aether 1 earbuds, exploded acoustic chamber, beryllium rotary diffusion driver, and sub-alphatonic power core.
- **Dynamic Audio Synthesis:** Interactive sound toggling and Web Audio API spatial frequency analyzer.
- **Responsive Layout:** Tailored experiences for desktop, tablet, and mobile devices.
- **Zero External Dependencies:** Self-contained assets, textures, and models.

## Local Development

